================================================================================
IMPORT/EXPORT FEATURE - SETUP & VERIFICATION
================================================================================

The import/export functionality has been successfully added to your Custom Page
Builder plugin. Follow these steps to verify everything is working correctly.

================================================================================
STEP 1: VERIFY FILES ARE IN PLACE
================================================================================

Check that these files exist in your plugin directory:

✓ admin/class-import-export.php
✓ admin/assets/js/import-export.js
✓ admin/assets/css/import-export.css

All files should be present and have recent modification dates.

================================================================================
STEP 2: CLEAR CACHE
================================================================================

1. Clear WordPress cache (if using a caching plugin)
2. Clear browser cache or do a hard refresh:
   - Windows/Linux: Ctrl + Shift + R
   - Mac: Cmd + Shift + R

================================================================================
STEP 3: VERIFY THE FEATURE IS LOADED
================================================================================

1. Log into WordPress admin
2. Go to: Page Builder > All Pages
3. Open browser Developer Console (Press F12)
4. Look for these console messages:
   
   ✓ "CPB Import/Export: Script loaded"
   ✓ "CPB Import/Export: cpbAdmin available? true"

If you see these messages, the feature is loaded correctly!

================================================================================
STEP 4: TEST EXPORT FUNCTIONALITY
================================================================================

1. On the "All Pages" screen, find any existing page
2. Look for the "Export" link next to the page (after "Edit")
3. Click "Export"
4. Check the console for: "CPB Import/Export: Export button clicked"
5. A JSON file should automatically download to your computer
6. The filename will be: [page-slug]-export.json

SUCCESS: If the file downloads, export is working! ✓

================================================================================
STEP 5: TEST IMPORT FUNCTIONALITY
================================================================================

1. On the "All Pages" screen, look for the "Import Page" button
   (It's next to the "Add New" button at the top)
2. Click "Import Page"
3. Check the console for: "CPB Import/Export: Import button clicked"
4. A modal window should appear with a file upload form

SUCCESS: If the modal appears, import UI is working! ✓

5. Click "Choose File" and select the JSON file you exported in Step 4
6. Click "Import" button
7. You should see "Importing... Please wait."
8. After a moment, you'll see a success message
9. The page list will automatically refresh
10. You should see the imported page in the list (with a unique slug if needed)

SUCCESS: If the page appears in the list, import is working! ✓

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Console messages don't appear
SOLUTION: 
- Refresh the page with Ctrl+Shift+R
- Check if JavaScript files are loading (Network tab in DevTools)
- Verify file paths are correct

PROBLEM: Import button doesn't show modal
SOLUTION:
- Check console for JavaScript errors
- Verify jQuery is loaded: type "jQuery" in console
- Check if modal HTML exists: jQuery('#cpb-import-modal').length should return 1

PROBLEM: Export button doesn't download file
SOLUTION:
- Check console for errors
- Verify page ID is being passed: check data-page-id attribute
- Check Network tab for AJAX response

PROBLEM: "cpbAdmin is not defined" error
SOLUTION:
- Clear all caches
- Hard refresh browser
- Check if wp_localize_script is working

PROBLEM: Import fails with error
SOLUTION:
- Check WordPress debug.log for PHP errors
- Verify JSON file format is correct
- Ensure file is valid JSON (open in text editor)
