## 📝 Method 1: Upload from Computer

### Steps:
1. Click the **"📁 Upload Image"** button
2. WordPress Media Library opens
3. Click **"Upload Files"** tab
4. Drag and drop your image OR click **"Select Files"**
5. Choose image from your computer
6. Click **"Use Image"** button
7. ✅ Image URL is automatically filled in the text field
8. ✅ Image preview appears below

### Benefits:
- Easy and visual
- No need to know the image URL
- Automatic preview
- Works with WordPress media library

---

## 📝 Method 2: Enter Image URL Manually

### Steps:
1. Skip the upload button
2. Type or paste an image URL directly into the text field
3. Examples:
   - `https://example.com/images/photo.jpg`
   - `https://cdn.example.com/uploads/2024/image.png`
   - Or just an attachment ID like `123`
4. Press Tab or click outside the field
5. ✅ Image preview appears automatically

### Benefits:
- Fast if you already have the URL
- Works with external images (CDN, other websites)
- Can use attachment IDs
- No need to open media library

---

## 🎨 Both Methods Work Together!

## 🆘 Troubleshooting

### Upload button doesn't work?
**Solution:** 
- Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
- Check JavaScript console (F12)
- Make sure WordPress media library works

### Preview doesn't show?
**Solution:**
- Make sure URL starts with `http://` or `https://`
- Check if image URL is valid
- Try clicking outside the text field
- If error shows "Invalid image URL", check the URL

### Can't type in text field?
**Solution:**
- Click directly in the text field
- Make sure you're not clicking the button
- Text field should be below the button

### Image doesn't save?
**Solution:**
- Make sure you filled the text field (either by upload or typing)
- Click "Create Page" or "Update Page" at bottom
- Check if preview appeared before saving
