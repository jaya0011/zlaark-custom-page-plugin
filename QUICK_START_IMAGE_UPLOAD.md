# 🚀 Quick Start: Upload Images

## 3 Simple Steps to Upload Images

### Step 1: Add or Edit a Section
```
WordPress Admin → Custom Pages → Add New Page
↓
Click "Add Section" button
↓
Select section type (Content Block, Hero Banner, etc.)
```

### Step 2: Click "Select Image"
```
Look for the "Select Image" button in the section configuration
↓
Click the button
↓
WordPress Media Library opens
```

### Step 3: Upload Your Image
```
Click "Upload Files" tab
↓
Drag and drop your image OR click "Select Files"
↓
Choose image from your computer
↓
Click "Use Image" button
↓
✅ Image preview appears!
```

---

## 📍 Where to Find the Upload Button

### Content Block Section
```
Section Configuration
├── Title
├── Subtitle
├── Layout
├── Content
└── 📸 Content Image
    ├── [Select Image] ← Click here!
    └── Image preview (appears after selection)
```

### Hero Banner Section
```
Section Configuration
├── Title
├── Subtitle
├── Text Alignment
└── 📸 Background Image
    ├── [Select Image] ← Click here!
    └── Image preview (appears after selection)
```

### Category Showcase Section
```
Section Configuration
├── Title
├── Layout
├── Columns
└── Categories
    └── Category 1
        ├── Title
        ├── Link
        └── 📸 Category Image
            ├── [Select Image] ← Click here!
            └── Image preview (appears after selection)
```

### Product Grid Section
```
Section Configuration
├── Title
├── Layout
├── Columns
└── Products
    └── Product 1
        ├── 📸 Product Image
        │   ├── [Select Image] ← Click here!
        │   └── Image preview (appears after selection)
        ├── Title
        ├── Price
        └── Description
```

## 🔄 To Change an Image

1. Click **"Remove"** button to clear current image
2. Click **"Select Image"** button
3. Upload or select a different image
4. Click **"Use Image"**
5. New image replaces the old one

---

## ➕ To Add Multiple Images

### For Categories:
1. Click **"Add Category"** button at the bottom
2. New category form appears
3. Fill in category details
4. Click **"Select Image"** for that category
5. Upload image
6. Repeat for each category

### For Products:
1. Click **"Add Product"** button at the bottom
2. New product form appears
3. Fill in product details
4. Click **"Select Image"** for that product
5. Upload image
6. Repeat for each product

---

## ✅ Success Indicators

### You'll know it's working when:
- ✅ Media Library opens when you click "Select Image"
- ✅ Image preview appears after selection
- ✅ "Remove" button appears next to "Select Image"
- ✅ Section saves without errors
- ✅ Image displays on your published page

## 🆘 Troubleshooting

### Button doesn't work?
- Hard refresh: **Ctrl+Shift+R** (Windows) or **Cmd+Shift+R** (Mac)
- Check JavaScript is enabled
- Try a different browser

### Can't upload images?
- Check file size (max 2MB recommended)
- Check file type (JPG, PNG, GIF, WebP only)
- Check WordPress upload permissions

### Image doesn't save?
- Make sure you clicked **"Save Section"**
- Make sure you clicked **"Save Page"**
- Check browser console for errors (F12)
