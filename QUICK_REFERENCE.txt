┌──────────────────────────────────────────────────────────────────────────────┐
│  ⚡ QUICK START                                                               │
└──────────────────────────────────────────────────────────────────────────────┘

  1. Go to: Page Builder → Add New
  2. Click: "+ Content Block" or "+ Hero Slider"
  3. Find: "Section Image:" field
  4. Choose:
     • Click "Upload Image" to browse
     • OR type URL in text field
  5. Preview: Image appears automatically
  6. Save: Click "Create Page" at bottom

┌──────────────────────────────────────────────────────────────────────────────┐
│  💡 TIPS                                                                      │
└──────────────────────────────────────────────────────────────────────────────┘

  • Use upload button for local images (fastest)
  • Use text field for external URLs (quickest)
  • Preview confirms image is valid
  • Can switch between methods anytime
  • Each section has its own image field
  • Images save when you click "Create Page"


┌──────────────────────────────────────────────────────────────────────────────┐
│  🆘 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: Upload button doesn't work
  Solution: Hard refresh (Ctrl+Shift+R)

  Problem: Preview doesn't show
  Solution: Make sure URL starts with http:// or https://

  Problem: Image doesn't save
  Solution: Click "Create Page" or "Update Page" at bottom

  Problem: Still having issues?
  Solution: Press F12 → Console tab → Check for errors
