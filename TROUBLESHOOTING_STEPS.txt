================================================================================
IMPORT/EXPORT NOT WORKING - TROUBLESHOOTING STEPS
================================================================================

If clicking Import or Export buttons does nothing, follow these steps IN ORDER:

================================================================================
STEP 1: HARD REFRESH THE PAGE (30 seconds)
================================================================================

The most common issue is cached JavaScript files.

Windows/Linux: Press Ctrl + Shift + R
Mac: Press Cmd + Shift + R

This forces the browser to reload all files, ignoring cache.

After refreshing, try clicking Import or Export again.

✓ WORKED? Great! You're done.
✗ DIDN'T WORK? Continue to Step 2.

================================================================================
STEP 2: CLEAR BROWSER CACHE (1 minute)
================================================================================

1. Open browser settings
2. Find "Clear browsing data" or "Clear cache"
3. Select "Cached images and files"
4. Clear cache
5. Close and reopen browser
6. Go back to Page Builder > All Pages

Try clicking Import or Export again.

✓ WORKED? Great! You're done.
✗ DIDN'T WORK? Continue to Step 3.

================================================================================
STEP 3: RUN DEBUG SCRIPT (2 minutes)
================================================================================

1. Go to Page Builder > All Pages
2. Press F12 to open Developer Console
3. Click on the "Console" tab
4. Copy the ENTIRE contents of CONSOLE_DEBUG_SCRIPT.js
5. Paste into the console
6. Press Enter

The script will run tests and show you exactly what's wrong.

Look at the output:
- If tests PASS: The feature should work
- If tests FAIL: Read the error messages for specific issues

Common failures and fixes:

FAIL: "jQuery is not loaded"
FIX: Refresh the page, make sure you're in WordPress admin

FAIL: "cpbAdmin is not defined"
FIX: Clear cache, hard refresh, check if scripts are loading

FAIL: "Import button exists"
FIX: Make sure you're on "All Pages" screen, not "Add New"

FAIL: "import-export.js is loaded"
FIX: Check if file exists, check file permissions

✓ ALL TESTS PASS? Continue to Step 4.
✗ TESTS FAIL? Fix the issues shown, then retry.

================================================================================
STEP 4: CHECK BROWSER CONSOLE FOR ERRORS (1 minute)
================================================================================

1. Keep Developer Console open (F12)
2. Click on the "Console" tab
3. Look for RED error messages
4. Try clicking Import or Export
5. Watch for new error messages

Common errors and fixes:

ERROR: "Uncaught ReferenceError: cpbAdmin is not defined"
FIX: Scripts not loading in correct order. Clear cache and refresh.

ERROR: "Uncaught TypeError: Cannot read property 'ajaxUrl'"
FIX: cpbAdmin object is incomplete. Check wp_localize_script.

ERROR: "404 Not Found" for import-export.js
FIX: File is missing or in wrong location. Check file path.

ERROR: "Uncaught SyntaxError"
FIX: JavaScript file has syntax error. Re-upload the file.

✓ NO ERRORS? Continue to Step 5.
✗ ERRORS FOUND? Fix them based on the messages above.

================================================================================
STEP 5: CHECK NETWORK TAB (2 minutes)
================================================================================

1. Open Developer Tools (F12)
2. Click on "Network" tab
3. Reload the page (F5)
4. Look for these files in the list:
   - import-export.js
   - import-export.css
   - admin.js

Check the Status column:
- 200 = File loaded successfully ✓
- 404 = File not found ✗
- 403 = Permission denied ✗
- 500 = Server error ✗

If you see 404 errors:
1. Check if files exist in: wp-content/plugins/[plugin-name]/admin/assets/
2. Check file names are correct (case-sensitive)
3. Check file permissions (should be readable)

If you see 403 errors:
1. Check file permissions
2. Check .htaccess rules
3. Contact your hosting provider

If you see 500 errors:
1. Check WordPress debug.log
2. Check PHP error logs
3. May be a PHP syntax error

✓ ALL FILES LOAD (200)? Continue to Step 6.
✗ FILES DON'T LOAD? Fix file issues first.

================================================================================
STEP 6: VERIFY YOU'RE ON THE CORRECT PAGE (30 seconds)
================================================================================

The import/export buttons ONLY appear on the "All Pages" screen.

Make sure you're at:
WordPress Admin > Page Builder > All Pages

NOT at:
- Page Builder > Add New
- Any other admin page

The URL should look like:
.../wp-admin/admin.php?page=custom-page-builder

✓ ON CORRECT PAGE? Continue to Step 7.
✗ WRONG PAGE? Navigate to "All Pages" screen.

================================================================================
STEP 7: CHECK IF ELEMENTS EXIST (1 minute)
================================================================================

Open Console (F12) and run these commands:

Check import button:
jQuery('#cpb-import-page-btn').length

Expected: 1
If 0: Button HTML is not in the page

Check export buttons:
jQuery('.cpb-export-page').length

Expected: Number of pages you have (e.g., 3)
If 0: No pages exist, or HTML is not rendered

Check modal:
jQuery('#cpb-import-modal').length

Expected: 1
If 0: Modal HTML is not in the page

If any return 0:
1. View page source (Ctrl+U)
2. Search for "cpb-import-page-btn"
3. If not found: Plugin may not be rendering HTML correctly
4. Try deactivating and reactivating the plugin

✓ ALL ELEMENTS EXIST? Continue to Step 8.
✗ ELEMENTS MISSING? Check plugin activation and page rendering.

================================================================================
STEP 8: MANUALLY TEST MODAL (30 seconds)
================================================================================

Open Console (F12) and run:

jQuery('#cpb-import-modal').css('display', 'flex')

The modal should appear on screen.

✓ MODAL APPEARS? JavaScript and CSS are working. Issue is with click handlers.
✗ MODAL DOESN'T APPEAR? CSS issue or modal HTML is broken.

If modal appears but buttons don't work:
1. Event handlers are not attached
2. Run the debug script from Step 3
3. Check for JavaScript errors

If modal doesn't appear:
1. Check if import-export.css is loaded
2. Check for CSS conflicts
3. Try in a different browser

================================================================================
STEP 9: TEST AJAX MANUALLY (2 minutes)
================================================================================

Test if the server-side code works by running this in Console:

jQuery.ajax({
    url: cpbAdmin.ajaxUrl,
    type: 'POST',
    data: {
        action: 'cpb_export_page',
        nonce: cpbAdmin.nonce,
        page_id: 1
    },
    success: function(response) {
        console.log('SUCCESS:', response);
    },
    error: function(xhr, status, error) {
        console.error('ERROR:', error);
    }
});

Replace page_id: 1 with an actual page ID from your list.

Expected: SUCCESS with page data
If ERROR: Server-side issue

Common server errors:
- "Invalid nonce": Refresh page and try again
- "Page not found": Use a valid page ID
- "500 Internal Server Error": Check WordPress debug.log

✓ AJAX WORKS? Server is fine. Issue is with click handlers.
✗ AJAX FAILS? Server-side issue. Check PHP errors.

================================================================================
STEP 10: DEACTIVATE/REACTIVATE PLUGIN (1 minute)
================================================================================

Sometimes the plugin needs to be reinitialized:

1. Go to WordPress Admin > Plugins
2. Find "Zlaark Custom Page Builder"
3. Click "Deactivate"
4. Wait 5 seconds
5. Click "Activate"
6. Go back to Page Builder > All Pages
7. Hard refresh (Ctrl+Shift+R)

Try Import/Export again.

✓ WORKED? Plugin needed reinitialization.
✗ DIDN'T WORK? Continue to Step 11.

================================================================================
STEP 11: CHECK FOR PLUGIN CONFLICTS (5 minutes)
================================================================================

Other plugins might be interfering:

1. Go to WordPress Admin > Plugins
2. Deactivate ALL other plugins (except Custom Page Builder)
3. Go to Page Builder > All Pages
4. Try Import/Export

✓ WORKS NOW? Another plugin was conflicting.
   - Reactivate plugins one by one to find the culprit
   
✗ STILL DOESN'T WORK? Continue to Step 12.

================================================================================
STEP 12: CHECK FOR THEME CONFLICTS (3 minutes)
================================================================================

Your theme might be interfering:

1. Go to WordPress Admin > Appearance > Themes
2. Activate a default WordPress theme (Twenty Twenty-Four, etc.)
3. Go to Page Builder > All Pages
4. Try Import/Export

✓ WORKS NOW? Your theme was conflicting.
   - Contact theme developer
   - Or keep using default theme for admin
   
✗ STILL DOESN'T WORK? Continue to Step 13.

================================================================================
STEP 13: CHECK FILE PERMISSIONS (2 minutes)
================================================================================

Files might not be readable:

SSH or FTP into your server and check:

wp-content/plugins/[plugin-name]/admin/assets/js/import-export.js
wp-content/plugins/[plugin-name]/admin/assets/css/import-export.css
wp-content/plugins/[plugin-name]/admin/class-import-export.php

Permissions should be:
- Files: 644 (rw-r--r--)
- Directories: 755 (rwxr-xr-x)

To fix permissions:
chmod 644 import-export.js
chmod 644 import-export.css
chmod 644 class-import-export.php

✓ PERMISSIONS FIXED? Try again.
✗ PERMISSIONS OK? Continue to Step 14.

================================================================================
STEP 14: ENABLE WORDPRESS DEBUG MODE (3 minutes)
================================================================================

Check for PHP errors:

1. Edit wp-config.php
2. Add these lines before "That's all, stop editing!":

define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);
define('WP_DEBUG_DISPLAY', false);

3. Save the file
4. Go to Page Builder > All Pages
5. Try Import/Export
6. Check wp-content/debug.log for errors

Common PHP errors:
- "Class not found": class-import-export.php not loaded
- "Fatal error": Syntax error in PHP file
- "Permission denied": File permission issue

Fix any errors found, then try again.

================================================================================
STEP 15: TRY A DIFFERENT BROWSER (2 minutes)
================================================================================

Browser-specific issues:

1. Try Chrome (if you were using Firefox)
2. Try Firefox (if you were using Chrome)
3. Try Edge or Safari

✓ WORKS IN DIFFERENT BROWSER? Original browser has issues.
   - Clear cache in original browser
   - Update browser to latest version
   - Check browser extensions
   
✗ DOESN'T WORK IN ANY BROWSER? Server-side issue.

================================================================================
STEP 16: CHECK SERVER REQUIREMENTS (1 minute)
================================================================================

Verify your server meets requirements:

- WordPress 5.0 or higher
- PHP 7.4 or higher
- jQuery loaded (WordPress default)

Check PHP version:
1. WordPress Admin > Tools > Site Health
2. Look for PHP version

If PHP < 7.4:
- Contact hosting provider to upgrade
- Plugin requires PHP 7.4+

================================================================================
STEP 17: RE-UPLOAD FILES (5 minutes)
================================================================================

Files might be corrupted:

1. Download fresh copies of:
   - admin/assets/js/import-export.js
   - admin/assets/css/import-export.css
   - admin/class-import-export.php

2. Upload via FTP/SFTP to correct locations

3. Overwrite existing files

4. Clear all caches

5. Hard refresh browser

6. Try Import/Export again

================================================================================

================================================================================

If you've tried everything above and it still doesn't work, collect:

1. WordPress version
2. PHP version
3. Browser and version
4. Output from CONSOLE_DEBUG_SCRIPT.js
5. Screenshots of console errors
6. Screenshots of Network tab
7. Contents of wp-content/debug.log
8. List of active plugins
9. Active theme name

Then contact plugin support with all this information.
