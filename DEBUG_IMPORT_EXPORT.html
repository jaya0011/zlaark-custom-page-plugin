🔍 Import/Export Debug Test

This page helps you debug the import/export functionality. Open your browser's Developer Console (F12) to see detailed logs.

Step 1: Check WordPress Admin

This test must be run from the WordPress admin area. Copy and paste these commands into your browser console while on the Page Builder > All Pages screen:

Test 1: Check if jQuery is loaded

typeof jQuery

Expected result: "function"

Test 2: Check if cpbAdmin is defined

console.log(cpbAdmin)

Expected result: Object with ajaxUrl and nonce properties

Test 3: Check if import button exists

jQuery('#cpb-import-page-btn').length

Expected result: 1

Test 4: Check if export buttons exist

jQuery('.cpb-export-page').length

Expected result: Number of pages in your list (e.g., 3 if you have 3 pages)

Test 5: Check if modal exists

jQuery('#cpb-import-modal').length

Expected result: 1

Test 6: Check if import-export script is loaded

jQuery('script[src*="import-export.js"]').length

Expected result: 1

Test 7: Manually trigger import modal

jQuery('#cpb-import-modal').css('display', 'flex')

Expected result: Modal should appear on screen

Test 8: Check console for import/export messages

Look for these messages in the console:

  • CPB Import/Export: DOM ready, starting initialization
  • CPB Import/Export: Initializing...
  • CPB Import/Export: Script fully loaded and ready

Step 2: Common Issues & Solutions

Issue: "jQuery is not defined"

Problem: jQuery is not loaded
Solution: Make sure you're on a WordPress admin page. jQuery should be loaded automatically.

Issue: "cpbAdmin is not defined"

Problem: The localized script data is not available
Solution:
  • Hard refresh the page (Ctrl+Shift+R or Cmd+Shift+R)
  • Clear browser cache
  • Check if you're on the correct page (Page Builder > All Pages)

Issue: Import button doesn't exist (length = 0)

Problem: The HTML element is not in the page
Solution:
  • Verify you're on the "All Pages" screen, not "Add New"
  • Check if the plugin is activated
  • Look at the page source to see if the button HTML is there

Issue: Script is not loaded (length = 0)

Problem: The JavaScript file is not being enqueued
Solution:
  • Check file exists: wp-content/plugins/[plugin-name]/admin/assets/js/import-export.js
  • Check file permissions (should be readable)
  • Look in Network tab for 404 errors

Step 3: Manual Testing

Test Export Manually

Run this in the console to test export without clicking:

jQuery.ajax({
    url: cpbAdmin.ajaxUrl,
    type: 'POST',
    data: {
        action: 'cpb_export_page',
        nonce: cpbAdmin.nonce,
        page_id: 1  // Change to an actual page ID
    },
    success: function(response) {
        console.log('Export response:', response);
    },
    error: function(xhr, status, error) {
        console.error('Export error:', error);
    }
});

Test Import Modal Manually

Run this in the console to show the modal:

jQuery('#cpb-import-modal').css('display', 'flex').addClass('active');

Check Event Handlers

Run this to see if click handlers are attached:

jQuery._data(jQuery('#cpb-import-page-btn')[0], 'events')

Expected result: Should show click event

Step 4: Check Network Tab

  1. Open Developer Tools (F12)
  2. Go to the Network tab
  3. Reload the Page Builder > All Pages screen
  4. Look for these files:
    • import-export.js - Should load with status 200
    • import-export.css - Should load with status 200
  5. If you see 404 errors, the files are not in the correct location

Step 5: Enable WordPress Debug Mode

Add these lines to your wp-config.php file:

define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);
define('WP_DEBUG_DISPLAY', false);

Then check wp-content/debug.log for any PHP errors.

Quick Fix Checklist

Try these in order:
  1. Hard refresh the page (Ctrl+Shift+R)
  2. Clear browser cache completely
  3. Clear WordPress cache (if using a caching plugin)
  4. Deactivate and reactivate the plugin
  5. Check browser console for errors
  6. Check Network tab for failed file loads
  7. Verify file permissions
  8. Test in a different browser
  9. Disable other plugins temporarily
  10. Switch to a default WordPress theme temporarily
