│                                                                              │
│  💡 TIPS & TRICKS                                                            │
│  ═════════════════                                                           │
│                                                                              │
│  ✓ To change an image: Click "Remove" then "Select Image" again             │
│  ✓ To add multiple images: Use Category Showcase or Product Grid            │
│  ✓ Recommended image size: Max 2048x2048px, under 1MB                       │
│  ✓ Supported formats: JPG, PNG, GIF, WebP                                   │
│  ✓ Always add alt text for accessibility                                    │

│  🆘 TROUBLESHOOTING                                                          │
│  ══════════════════                                                          │
│                                                                              │
│  Problem: Button doesn't work                                               │
│  Solution: Hard refresh (Ctrl+Shift+R) and try again                        │
│                                                                              │
│  Problem: Can't upload images                                               │
│  Solution: Check file size and format (JPG, PNG, GIF, WebP only)            │
│                                                                              │
│  Problem: Image doesn't save                                                │
│  Solution: Make sure you clicked both "Save Section" AND "Save Page"        │
│                                                                              │
│  Problem: Image doesn't show on page                                        │
│  Solution: Check FRONTEND_IMAGE_USAGE.md for React integration              │
